# Choice vs. rejection frame: the 100 stimuli as twins see them

Each twin sees all 100 stimuli in both frames, and every stimulus x frame is a separate call with no memory of the others. The two frames differ only in the line on screen 2. The order of the answer options is random per twin x stimulus and the same in both conversations, and screen 1 describes the options in that same order; here the option listed first is the scale's left end (1).

>
> Please think about which of the two options you would prefer.
> ---

> 4 = No preference
